# Régression linéaire multiple – Prédiction de notes d'examen

Projet universitaire (Université Paris Dauphine-PSL, 2025) réalisé en R.

## Objectif
Construire un modèle de régression linéaire multiple reliant la note d'examen
aux facteurs explicatifs disponibles, avec un double objectif :
- **interprétation** : mesurer l'effet de chaque facteur sur la note ;
- **prédiction** : estimer la note d'un nouvel étudiant.

Le modèle final devait être parcimonieux, statistiquement justifié
et reproductible.
